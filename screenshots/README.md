# Screenshots

This directory contains visual captures demonstrating the features of the Shopping List application:

### 1. All Items View
Displaying the full shopping list with active items, category tags, and filter chips.
![All Items](all%20items.png)

### 2. Quantity Management (`quantities.png`)
Demonstrates the `−` and `+` quantity increment/decrement controls, bounded so counts cannot drop below 1.
![Quantities](quantities.png)

### 3. Undo Deletion (`undo.png`)
Demonstrates the `SnackBar` displaying `"<Item> removed"` with an active **Undo** action button to restore items.
![Undo Action](undo.png)

### 4. Filter Views (`bought_filter.png`)
Demonstrates filtering by status (showing the "Bought" filter tab with strikethrough styling).
![Bought Filter](bought_filter.png)

### 5. Item Details & Quick Edit (`item_details.png`)
Demonstrates the modal bottom sheet (offcanvas form) for editing an item's name, note, category chips, and bought state.
![Item Details](item_details.png)
